# Historical validation records

The other files in this directory are retained records from earlier development
checkpoints. They describe their own source revisions, synthetic fixtures,
toolchains and limitations; they are **not** a test pass for today's source.

For the current candidate's exact source identity, native repair results, remaining
Settings accessibility-test failure and unverified hardware/accessibility/install
work, read [Validation status](../Docs/VALIDATION.md). Do not add historical test
counts together or reuse earlier build/runtime results to certify a different
source tree. A narrow development-Mac smoke check is not supported binary-release
acceptance.
