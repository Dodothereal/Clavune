# Historical validation records

The other files in this directory are retained records from earlier development
checkpoints. They describe their own source revisions, synthetic fixtures,
toolchains and limitations; they are **not** a test pass for today's source.

For the current candidate's exact identities and evidence, read
[Validation status](../Docs/VALIDATION.md). Native launch, real file-panel/IME
behavior, current full Swift validation and supported binary-release acceptance
remain open. Do not add the historical test counts together or reuse historical
build/runtime results to certify a different source tree.
